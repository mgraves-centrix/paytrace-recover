# Recovery desk dashboard direction

Audience and task: a merchant opening the workspace to see what needs a decision, what is running, and whether access has been verified.

Feeling: calm, decisive, trustworthy. Preserve PayTrace's blue/white merchant UI, existing type, components, and status colors. The supplied November 8 desk photo showed an oversized three-column view with two empty columns; the dashboard gives the active queue the majority of the width.

Composition: compact status totals first, priority cases in a wide left panel, other activity in a narrow right panel, then connected-result status and the explicitly fictional completed sample. Each row opens its case. The complete queue and detailed health remain available below. On mobile, status totals stay compact, followed by the priority queue and the activity panel.

Truthful data: all totals and rows come from the existing workspace overview. No fabricated verified outcome or connected PayPal/Render claim is introduced. The sample remains labeled as fictional with no provider calls.

Motion and assets: no new animation or imagery. The dashboard is a working surface; the visual emphasis is on next action and legible status. Existing focus and reduced-motion behavior applies.
