# Activity and judge walkthrough visual brief

November 8, 2026. PayTrace Recover's blue and white product language stays intact. The Activity view is a wide case ledger: a concise record overview, clear search and type filters, then full-width events with customer, action, time, case ID, and an open-case affordance. It should feel operational and calm, with high enough density to scan without shrinking the type. The existing compact recent-activity widget remains separate.

The judge page is an editorial product story. Its first view pairs the paid-but-locked-out headline with a three-state case diagram. The diagram is illustrative and labeled fictional. A single three-stop route links into the same eight-moment sample; the working merchant desk follows. Configuration and connected proof are disclosed below, never implied by the sample. Related safety tools are optional follow-on links, not competing routes.

Desktop uses a split hero and three route cards. Mobile stacks copy, the legible diagram, then route cards. The evidence standard stays accessible in a native disclosure. The visual direction uses deep navy for the narrative, blue for actions and evidence, warm amber only for the access mismatch, and white surfaces for scan-heavy work.
